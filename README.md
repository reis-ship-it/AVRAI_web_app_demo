# AVRAI Web App Demo

A fully clickable Wizard-of-Oz prototype for AVRAI, a UAB and Birmingham discovery app
for new university students.

## Local scripts

- `npm run dev` starts the Vite dev server.
- `npm run build` typechecks and builds the static production app.
- `npm run preview` serves the production build locally.

The prototype is intentionally self-contained: mock data, local state, no auth, no
database, no backend, no external API calls.
